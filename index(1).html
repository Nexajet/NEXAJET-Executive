SOBRE NEXAJETABOUT NEXAJET

Nace en Madrid.
Vuela donde sea.Born in Madrid.
Flies anywhere.

NexaJet es un proyecto de aviación de negocios virtual con base conceptual en Madrid (LEMD), operado íntegramente dentro de X-Plane 12. No es una compañía real ni ofrece servicios de aviación reales: es una operación de simulación construida con el mismo rigor que exigiría una compañía de verdad.NexaJet is a virtual business aviation project conceptually based in Madrid (LEMD), operated entirely within X-Plane 12. It is not a real company and does not offer real aviation services — it's a simulation operation built with the same rigor a real one would demand.

La flota se piensa como una progresión deliberada, no como una colección: cada aeronave añade una capacidad que la anterior no tenía.The fleet is designed as a deliberate progression, not a collection: each aircraft adds a capability the previous one lacked.
